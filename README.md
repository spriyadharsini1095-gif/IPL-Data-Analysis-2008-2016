# 🏏 IPL Data Analysis Using Power BI

## 📌 Project Overview
Analysis of Indian Premier League (IPL) 
data from 2008-2016 using Power BI to 
generate insights about player performance,
team success, toss decisions and venues.

## 📊 Dashboard Pages
- **Player Stats** — Runs, Wickets, Catches
- **Team Analysis** — Wins, Sixes, Fours
- **Toss Analysis** — Decisions & Win %
- **Venue Stats** — Cities & Lucky Stadiums

## 🔍 Key Analysis
- Highest & lowest scorers
- Top bowlers & wicket analysis
- Top fielders (catches & run-outs)
- Toss impact on match outcomes
- Most successful IPL teams
- Most sixes & fours by players/teams
- Lucky stadiums for top teams

## 📁 Files Included
- IPL_Data_Analysis.pbix (Power BI file)
- IPL_Data_Analysis_Report.docx (Report)
- matches.csv (636 matches dataset)
- deliveries.csv (150,460 rows dataset)

## 🛠️ Tools Used
- Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- MySQL
- Python (Pandas)

## 💡 Key Insights
- Virat Kohli — All time highest scorer
- SL Malinga — Most wickets (170+)
- MI & CSK — Most successful (5 titles each)
- 57% teams prefer fielding after toss
- Wankhede Stadium — MI's lucky ground
